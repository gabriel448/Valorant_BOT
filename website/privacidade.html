Política de Privacidade

Última atualização: maio de 2026. Como o Explanator coleta, usa e protege seus dados.

1. Responsável pelo Tratamento

O Explanator é um bot de Discord desenvolvido e mantido de forma independente. Para qualquer questão relacionada a dados pessoais, entre em contato pelo e-mail soooosa0610@gmail.com.

2. Dados Coletados

O Explanator coleta e armazena apenas os dados estritamente necessários para seu funcionamento:

  • Riot ID (Nome#TAG) — fornecido voluntariamente pelo administrador do servidor via /cadastrar-alvo
  • Dados de partidas competitivas — obtidos via Riot Games API: resultado, K/D ratio, elo, kills, mortes, assistências e headshot %
  • ID do servidor Discord — para associar configurações e jogadores ao servidor correto
  • ID do canal Discord — configurado via /ativar-esse-canal para envio de notificações

Nenhum dado adicional é coletado. O bot não acessa mensagens privadas, não monitora outros canais e não coleta nenhuma informação fora do escopo acima.

3. Finalidade do Tratamento

Os dados são usados exclusivamente para:

  • Detectar o término de partidas competitivas dos jogadores cadastrados
  • Analisar o desempenho da partida com base nos critérios definidos (K/D, sequências, bodyshot %)
  • Enviar notificações automáticas no canal configurado pelo administrador
  • Calcular e exibir o ranking interno do servidor (sistema Anti-Rank)

4. Contexto de Uso

O Explanator é projetado para uso em servidores privados de grupos de amigos. Os jogadores monitorados são cadastrados pelo administrador do servidor — geralmente com conhecimento e consentimento implícito do grupo. O bot não é projetado para monitorar jogadores sem o contexto de um grupo fechado.

5. Fonte dos Dados

Todos os dados de partida são obtidos diretamente da Riot Games API, acessando exclusivamente informações públicas dos perfis cadastrados. O Explanator não cria, infere ou altera esses dados — apenas os processa conforme recebido da API oficial, em conformidade com os Termos de Uso para Desenvolvedores da Riot Games.

6. Retenção de Dados

Os dados de um jogador são mantidos enquanto ele estiver cadastrado no sistema do servidor. Históricos de partida são utilizados apenas para cálculos de sequências consecutivas e pontuação do Anti-Rank — não são armazenados de forma indefinida nem utilizados para outros fins.

Dados de servidores onde o bot foi removido são excluídos em até 30 dias.

7. Compartilhamento

Nenhum dado coletado é vendido, alugado, compartilhado ou transferido a terceiros. Os dados permanecem no banco de dados interno do bot e são utilizados exclusivamente para as finalidades descritas nesta política.

8. Seus Direitos

Você pode a qualquer momento:

  • Remover seus dados — use o comando /remover-alvo no Discord ou envie um e-mail para soooosa0610@gmail.com
  • Consultar quais dados estão armazenados — use /status-explanator no Discord ou solicite por e-mail
  • Solicitar correção de dados incorretos — entre em contato pelo e-mail
  • Solicitar exportação dos seus dados — entre em contato pelo e-mail

Solicitações enviadas por e-mail são atendidas em até 7 dias úteis.

9. Segurança

O banco de dados do Explanator é mantido em ambiente privado com acesso restrito ao desenvolvedor. Riot IDs e dados de partida não são expostos publicamente — as notificações são enviadas apenas no canal Discord configurado pelo administrador do próprio servidor.

10. Conformidade com a Riot Games

O Explanator utiliza a Riot Games API exclusivamente para as finalidades descritas nesta política, em total conformidade com os Riot Games Developer Policies. Os dados de partida não são redistribuídos, revendidos ou utilizados para fins comerciais.

O Explanator não é endossado pela Riot Games e não reflete a opinião ou os valores da Riot Games.

11. Alterações nesta Política

Esta política pode ser atualizada para refletir mudanças no funcionamento do bot ou em requisitos legais aplicáveis. A data da última atualização é sempre indicada no topo deste documento. Mudanças significativas serão comunicadas nos servidores onde o bot está ativo.
